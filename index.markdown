# **Bine de știut**

**Tonalitatea.** Tonalitatea mostrelor este indicativă. În cazul anumitor produse, pentru obținerea unor efecte particulare, în aceleași cutii se găsesc plăci ce au tonalități diferite.

**Calibrele.** Diferențele de calibru pot fi de +/- 0,6% conform normelor, în cazul gresiei porțelanate. De exemplu, considerând o placă de 30x30, înseamnă 1,8 mm.

**Planeitatea.** Este permisă o diferență de +/- 0,5% față de norme.

**Calitatea.** Este garantată numai calitatea I, dacă materialul nu a fost pus în operă și dacă defectul de pe suprafața plăcii este vizibil de la o distanță mai mare de 1 m.

**Piesele speciale.** Dat fiind faptul că provin din cuptoare diferite, temperaturi și timpi de coacere diferiți, este dificilă obținerea aceleiași tonalități a pieselor speciale cu fondul.

**Klinker-ul**

- Pentru a se garata rezistența la îngheț / dezgheț și dilatație termică este obligatorie realizarea rostului de 7-10 mm.

- Calibrele: Klinker-ul nu este calibrat, el fiind un produs trafilat, nu un produs obținut prin presare.

- Tonalitatea: Klinker-ul nu are tonalitate. Tehnica de împrăștiere neomogenă a sărurilor pe suprafața plăcii generează obținerea efectului rustic dorit. Având tonalități diferite, pentru a se obține un efect omogen este necesară desfacerea a 4-5 cutii din care să se aleagă plăcile care urmează a fi montate, apropiate ca tonalitate.
